Project: Some Emissions

Group members: Kyryl Andreiev, Jarod Atienzo, Dylan Verallo, Jesse Wattenhofer
Github Repository
Description

Some Emissions is a project that seeks to increase public awareness of electricity production and emissions that are produced from it. A user can input their city and get information on their power company. Users can view current and historical data to gain a better picture of where their power comes from.
